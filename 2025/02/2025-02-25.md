# 25 February 2025

Two prompt collections for configuring large language models: a set of general system prompts intended to encourage neutral behaviour, and a user interface that combines model and user characteristics to generate more targeted prompts.

## GitHub Repositories

2 repos created

- **[General System Prompts](https://github.com/danielrosehill/General-System-Prompts)** (GitHub, Prompt collection): Some system prompts intended to (attempt to) configure neutral behavior from LLMs
- **[System Prompt Factory](https://github.com/danielrosehill/System-Prompt-Factory)** (GitHub, Prompt collection): A system prompt generation UI that combines model and user characteristics to generate more targeted (but still general) system prompts for LLMs
