# 23 November 2025

Two repositories cover speech recognition tooling: a GUI for collecting audio and text into organised training datasets, and a validated script for fine-tuning Whisper on Modal GPUs with preformatted audio data.

## GitHub Repositories

2 repos created

- **[ASR Training Data Collector](https://github.com/danielrosehill/ASR-Training-Data-Collector)** (GitHub, Tool): GUI to facilitate gathering training data for ASR/STT apps in organised datasets with audio capture, text capture, and JSONL metadata construction. - **[Modal Whisper Finetune Script](https://github.com/danielrosehill/Modal-Whisper-Finetune-Script)** (GitHub, Tool): Validated fine-tuning script for fine-tuning Whisper on Modal GPU with a preformatted audio dataset
