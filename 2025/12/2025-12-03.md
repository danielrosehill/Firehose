# 3 December 2025

Repositories cover agentic AI reporting and local infrastructure: an MCP example for long-form report generation, an MCP server for saving files to a NAS over NFS, and documentation for running local inference on AMD GPUs. Other work covers smart home Halacha, prompt experiments comparing speech cleanup approaches, and a dataset of captioned Israel photographs.

## GitHub Repositories

5 repos created

- **[All About MCP](https://github.com/danielrosehill/All-About-MCP)** (GitHub, MCP server): Example repository for agentic AI generated long form report generation
- **[AMD AI Server](https://github.com/danielrosehill/AMD-AI-Server)** (GitHub, Documentation): Local AI inference server for AMD GPU users
- **[Save To NAS MCP](https://github.com/danielrosehill/Save-To-NAS-MCP)** (GitHub, MCP server): An MCP server for saving files and folders to a local NAS over NFS. Eliminates repetitive steps when transferring data to NAS storage.
- **[Smart Home Halacha](https://github.com/danielrosehill/Smart-Home-Halacha)** (GitHub, Tool): Notebook on Halachic dimensions of smart home usage and Home Assistant
- **[Voice Cleanup Prompt Experiment](https://github.com/danielrosehill/Voice-Cleanup-Prompt-Experiment)** (GitHub, Prompt collection): Testing various permutations in system prompting for raw audio transcript cleanup and comparing multimodal ASR vs. the STT + LLM approach

## Datasets

1 dataset created

- **[Israel Photos](https://huggingface.co/datasets/danielrosehill/Israel-Photos)** (Hugging Face, Training dataset): A collection of 369 photographs captured across Israel between 2024 and 2025, with LLM-generated captions and location annotations. The images are sourced from the photographer's Pexels gallery.
