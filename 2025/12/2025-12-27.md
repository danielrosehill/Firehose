# 27 December 2025

Three tools for agent and desktop workflows: a recovery boot target for using an agentic CLI on Ubuntu, a slash command that pushes agents to reuse existing solutions, and a KDE Plasma action for quick background removal.

## GitHub Repositories

3 repos created

- **[Claude System Recovery Mode](https://github.com/danielrosehill/Claude-System-Recovery-Mode)** (GitHub, Tool): Boot target for using an agentic CLI for system recovery on Ubuntu (adapting to other GRUB-supporting OSes should be simple; for non-Linux envs, fork and modify).
- **[No Wheel Inventions](https://github.com/danielrosehill/No-Wheel-Inventions)** (GitHub, Tool): Slash command for Claude (and agents) to encourage them to avoid reinventing the wheel
- **[Quick RMBG](https://github.com/danielrosehill/Quick-RMBG)** (GitHub, Tool): Dolphin action for KDE Plasma to quickly invoke RMBG for background removal with support for two-pass and infinite-pass operation modes
