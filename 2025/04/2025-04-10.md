# 10 April 2025

Linux tools and AI prompt experiments filled the repositories: a Home Front Command wrapper, a list of MCP clients for Linux, and single-prompt book generation. Datasets covered system prompts for speech-to-text, careers, geopolitics, data work, email, prompt engineering, and general use.

## GitHub Repositories

5 repos created

- **[HFC Wrapper Linux](https://github.com/danielrosehill/HFC-Wrapper-Linux)** (GitHub, Tool): Home Front Command Wrapper - non-official, zero warranty offered!
- **[Linux MCP Clients](https://github.com/danielrosehill/Linux-MCP-Clients)** (GitHub, MCP server): A very small list of MCP clients that are available to Linux users, GUIs + CLIs
- **[One Prompt AI Book](https://github.com/danielrosehill/One-Prompt-AI-Book)** (GitHub, Prompt collection): Experiment - generating a book using a single prompt
- **[The Bot Has A Question](https://github.com/danielrosehill/The-Bot-Has-A-Question)** (GitHub, Documentation): Weird AI experiment #342
- **[The Jerusalem Odyssey Text](https://github.com/danielrosehill/The-Jerusalem-Odyssey-Text)** (GitHub, Tool): A 100 page book manuscript generated from a single prompt using Sonnet 3.7
