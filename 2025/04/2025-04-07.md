# 7 April 2025

Three prompt collections cover privacy screening for shared prompt libraries, system prompts for refining speech-to-text output, and a utility for combining text transformation prompts.

## GitHub Repositories

3 repos created

- **[Prompt Library Privacy Screener](https://github.com/danielrosehill/Prompt-Library-Privacy-Screener)** (GitHub, Prompt collection): Model for a PII screen (using Ollama) for open sourcing prompt libraries safely
- **[Speech To Text System Prompt Library](https://github.com/danielrosehill/Speech-To-Text-System-Prompt-Library)** (GitHub, Prompt collection): An updated skeleton library of system prompts for using LLMs to refine STT output
- **[Text Transformation Prompt Combiner](https://github.com/danielrosehill/Text-Transformation-Prompt-Combiner)** (GitHub, Prompt collection): Basic implementation of a prompt concatenation utility for text transformation system prompts for converting transcribed text
