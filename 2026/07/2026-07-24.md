# 24 July 2026

Shared 3D character models and a browser game about a race through Jerusalem cover the playful side. Elsewhere there are Linux tools for locking a keyboard, redacting images and monitoring porch noise, plus an ecommerce cart format, a WiFi rules reference and a storage system for renters.

## GitHub Repositories

9 repos created

- **[3D Models](https://github.com/danielrosehill/3D-Models)** (GitHub, Documentation): Shared 3D character models (Corn, Herman) for My Weird Prompts games and projects
- **[Claude Background Hook Planner](https://github.com/danielrosehill/Claude-Background-Hook-Planner)** (GitHub, Documentation): Placeholder — planning repo for a Claude Code background hook planner
- **[Dot Cart](https://github.com/danielrosehill/Dot-Cart)** (GitHub, Tool): An open, interoperable file format (.cart) for ecommerce shopping carts, designed for agentic AI
- **[Esp32 Porch Decibel Monitor](https://github.com/danielrosehill/esp32-porch-decibel-monitor)** (GitHub, Tool): Planning repo for a weatherproofed porch sensor documenting a nearby construction site (excavation phase, ~2 months to completion), reporting to Home Assistant.
- **[Hands Off](https://github.com/danielrosehill/hands-off)** (GitHub, Tool): Toddler-proof keyboard & mouse lock for Linux (evdev, works on X11 & Wayland)
- **[Image Sanitiser](https://github.com/danielrosehill/image-sanitiser)** (GitHub, Tool): Detection-assisted image redaction studio for Linux — find QR codes, faces and PII in photos, obfuscate them, and verify they're gone.
- **[Israel Wifi Regulations](https://github.com/danielrosehill/israel-wifi-regulations)** (GitHub, Documentation): Community reference: WiFi/RLAN spectrum rules in Israel (2.4/5/6 GHz) to help configure APs legally. Unofficial, dated snapshot — official authority is the Ministry of Communications.
- **[Race To The Shuk](https://github.com/danielrosehill/race-to-the-shuk)** (GitHub, Documentation): 🫓 Corn the Sloth vs Herman Poppleberry race through Jerusalem dodging giant falafel to grab the last pita in the shuk. Ridiculous 3D browser game.
- **[Warehouse Apartment](https://github.com/danielrosehill/warehouse-apartment)** (GitHub, Tool): Field manual for a home storage & moving system built on industrial logistics standards (Euroboxes, pallets, picking bins) — born of Israel's tenancy-at-will rental market.
