# 25 July 2026

Agent tooling and reference material for coding and hardware work appeared across several repositories. These covered a system prompt that makes coding agents document their findings, a plugin for building unofficial MCP servers, an index of hardware build documentation, and a parametric 3D model set for warehouse storage units. Israeli tax and regulatory material also featured, alongside an urban environmental data API blueprint.

## GitHub Repositories

8 repos created

- **[Document As You Go](https://github.com/danielrosehill/Document-As-You-Go)** (GitHub, Tool): A drop-in system prompt and slash command that make coding agents capture what they discover — undocumented APIs, auth flows, dead ends — instead of losing it when the session ends.
- **[Hardware Blueprints Index](https://github.com/danielrosehill/Hardware-Blueprints-Index)** (GitHub, Documentation): Index of repositories that document physical hardware builds — bills of materials, sourcing, wiring and enclosure specs, and firmware plans
- **[Israel Expense Classification Codes](https://github.com/danielrosehill/israel-expense-classification-codes)** (GitHub, Tool): Israel Tax Authority Form 6111 business expense classification codes as machine-readable JSON, plus the separate income tax and VAT deduction rules. Unofficial.
- **[Israel Reference Repos](https://github.com/danielrosehill/Israel-Reference-Repos)** (GitHub, Documentation): Index of Israel-related reference material: standards, regulations, classification codes, datasets, directories and translated official guidance.
- **[Noisycity API Blueprint](https://github.com/danielrosehill/noisycity-api-blueprint)** (GitHub, Tool): Blueprint for a public API for citizen-derived urban environmental data — noise, particulates and vibration from volunteer-operated monitoring stations. Planning repo; noisycity.org is a placeholder.
- **[Paperless Tax MCP](https://github.com/danielrosehill/paperless-tax-mcp)** (GitHub, MCP server): Unofficial MCP server and API documentation for paperless.tax (Israeli bookkeeping SaaS) — community reverse-engineering effort
- **[Storage Box 3d Models](https://github.com/danielrosehill/storage-box-3d-models)** (GitHub, Tool): Parametric GLB (glTF 2.0 binary) models of the standard industrial storage units you find in any warehouse, stockroom or workshop: euro stacking containers on the 600 × 400 mm module, an attached-lid...
- **[Unofficial MCP Builder Plugin](https://github.com/danielrosehill/Unofficial-MCP-Builder-Plugin)** (GitHub, Agent plugin): Claude Code plugin for authoring and maintaining unofficial MCP servers for third-party APIs — generate from the vendor's docs (verified against the live API), detect upstream drift, and smoke-test...
