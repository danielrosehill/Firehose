# 29 October 2026

New repositories covered voice-data preparation and rclone administration, with a tool that trims clicks from training recordings and agent skills for remotes, mounts and config backup. On Hugging Face, the work was wake-word and dictation cleanup: two "Hey Yossi" models, a fine-tune that edits raw dictation, and a reference dataset.

## GitHub Repositories

2 repos created

- **[Keyclick Detector](https://github.com/danielrosehill/Keyclick-Detector)** (GitHub, Tool): Detects keyboard and mouse clicks at the start and end of voice-training recordings so they can be trimmed. Trained on real recorder takes.
- **[Rclone Manager](https://github.com/danielrosehill/Rclone-Manager)** (GitHub, Agent plugin): Agent skills for routine rclone admin: install, remotes, mounts, config backup and migration, docs lookup

## Datasets

1 dataset created

- **[ASR Cleanup Before After](https://huggingface.co/datasets/danielrosehill/ASR-Cleanup-Before-After)** (Hugging Face, Reference dataset): No description published.

## AI Models

3 models created

- **[Hey Yossi microWakeWord](https://huggingface.co/danielrosehill/Hey-Yossi-microWakeWord)** (Hugging Face, Other): A custom "Hey Yossi" wake word for microWakeWord, trained 2026-10-29. It is a streaming, int8-quantised TFLite model of 61 KB.
- **[Hey Yossi openWakeWord](https://huggingface.co/danielrosehill/Hey-Yossi-openWakeWord)** (Hugging Face, Other): A custom "Hey Yossi" wake word for openWakeWord, trained 2026-10-29 for a personal voice assistant.
- **[S1 ASR Cleanup](https://huggingface.co/danielrosehill/S1-ASR-Cleanup)** (Hugging Face, Fine-tuned model): S1-ASR-Cleanup is a fine-tune of S1-mini by Superwhisper (superwhisper/s1-mini, Qwen3-0.6B) that cleans raw speech-to-text dictation the way one user edits his own.
