# 21 October 2026

Claude Code plugins for Bluetooth control on Linux, temporary network overflow, spam filtering, Maccabi Online skills, and a marketplace guide. Small text models handle paragraph breaks in speech-to-text output, bolding key lines in dictated emails, and swapping identifying details for substitutes.

## GitHub Repositories

10 repos created

- **[ASR Paragraph Breaks](https://github.com/danielrosehill/ASR-Paragraph-Breaks)** (GitHub, Tool): Hand-annotated paragraph breaks for flat ASR text, and a small text-in/text-out model trained on them
- **[Claude Agent Exchange](https://github.com/danielrosehill/Claude-Agent-Exchange)** (GitHub, Tool): A two-way file exchange between you and Claude Code: from-human / from-agent folders, a CLAUDE.md block, and a small explorer app locked to them
- **[Claude Linux BT Plugin](https://github.com/danielrosehill/Claude-Linux-BT-Plugin)** (GitHub, Agent plugin): Claude Code plugin: Bluetooth on Linux via bluetoothctl — scan, pair+trust+connect, manage, reset. Because the desktop dialogs don't.
- **[Claude Marketplace Guide Plugin](https://github.com/danielrosehill/Claude-Marketplace-Guide-Plugin)** (GitHub, Agent plugin): Start here for the danielrosehill Claude Code marketplace: browse plugins by theme, get recommendations, see what's new — read live from the manifest
- **[Claude Network Tmp Plugin](https://github.com/danielrosehill/Claude-Network-Tmp-Plugin)** (GitHub, Agent plugin): Claude Code plugin: capped, self-cleaning network overflow for a small or tmpfs /tmp
- **[Claude Pseudospam Filter Plugin](https://github.com/danielrosehill/Claude-Pseudospam-Filter-Plugin)** (GitHub, Agent plugin): Claude Code plugin: a second spam filter for pseudo-personalised outreach, taught by your own Gmail labels
- **[Gemma 3 270M Email Key Line Bolding](https://github.com/danielrosehill/Gemma-3-270M-Email-Key-Line-Bolding)** (GitHub, Tool): Gemma 3 270M fine-tune that bolds the key lines of a dictated email and changes nothing else
- **[Maccabi Online Skills](https://github.com/danielrosehill/Maccabi-Online-Skills)** (GitHub, Agent plugin): Unofficial Claude Code skills for Maccabi Online, the Maccabi Healthcare Services (Israel) member portal — drives your own signed-in Chrome
- **[Proximate Pseudonymizer](https://github.com/danielrosehill/Proximate-Pseudonymizer)** (GitHub, Tool): Small text-in/text-out model that swaps identifying details for proximate, consistent substitutes
- **[To Skill Or Not To Skill](https://github.com/danielrosehill/To-Skill-Or-Not-To-Skill)** (GitHub, Agent plugin): Before any task, ask: should this become a skill? A user-level heuristic for AI agents, as a Claude Code plugin plus a CLAUDE.md / AGENTS.md installer.

## Datasets

2 datasets created

- **[ASR Paragraph Breaks](https://huggingface.co/datasets/danielrosehill/ASR-Paragraph-Breaks)** (Hugging Face, Training dataset): Hand-annotated paragraph breaks for flat speech-to-text output. ASR engines emit punctuated, cased text as one block.
- **[Email Key Line Bolding](https://huggingface.co/datasets/danielrosehill/Email-Key-Line-Bolding)** (Hugging Face, Training dataset): Hand annotations of which words in a dictated email should be bold: any run of whole words within a paragraph, from a phrase to several sentences.

## AI Models

4 models created

- **[Gemma 3 270M ASR Paragraph Breaks](https://huggingface.co/danielrosehill/Gemma-3-270M-ASR-Paragraph-Breaks)** (Hugging Face, Fine-tuned model): Adds paragraph breaks to flat speech-to-text output and changes nothing else.
- **[Gemma 3 270M ASR Paragraph Breaks ONNX](https://huggingface.co/danielrosehill/Gemma-3-270M-ASR-Paragraph-Breaks-ONNX)** (Hugging Face, Fine-tuned model): ONNX export of danielrosehill/Gemma-3-270M-ASR-Paragraph-Breaks for ONNX Runtime, so it can run on a phone on the same runtime as an ONNX speech-recognition model.
- **[Gemma 3 270M Email Key Line Bolding](https://huggingface.co/danielrosehill/Gemma-3-270M-Email-Key-Line-Bolding)** (Hugging Face, Fine-tuned model): Puts the key parts of a dictated email in Markdown bold, and changes nothing else.
- **[Proximate Pseudonymizer 0.6B](https://huggingface.co/danielrosehill/Proximate-Pseudonymizer-0.6B)** (Hugging Face, Fine-tuned model): Try it: public demo Space · Write-up: blog post (runs on CPU and shows a word-level diff of every swap, so you can spot what it missed).
