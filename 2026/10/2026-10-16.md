# 16 October 2026

Agent tooling covers a per-turn context router, ChatGPT plugins, and skills for Israeli research and right-to-left work. Text classifiers sort voice-note transcripts into tasks and separate genuine stranger email from pseudo-personalised outreach. A dictation cleanup model and its evaluation dataset are planned.

## GitHub Repositories

7 repos created

- **[Agent Context Harness](https://github.com/danielrosehill/Agent-Context-Harness)** (GitHub, Tool): Per-turn router that sends each agent message to the current task, an existing parallel worker, or a new parallel session - context hygiene without compaction. Idea + prior-art scan.
- **[ASR Post Processor Model](https://github.com/danielrosehill/ASR-Post-Processor-Model)** (GitHub, Tool): Light-touch text-in/text-out model that cleans raw Parakeet v2 dictation: disfluencies, contractions, paragraphs. Planning stage.
- **[ChatGPT Plugins](https://github.com/danielrosehill/ChatGPT-Plugins)** (GitHub, Agent plugin): Daniel Rosehill's public plugins for ChatGPT (adapted from his Claude Code marketplace) as an importable plugin marketplace catalogue
- **[Israel Research Skills](https://github.com/danielrosehill/Israel-Research-Skills)** (GitHub, Agent plugin): Israel-specific research skills for Claude and ChatGPT: Kol Zchut rights, Home Front Command guidelines, NSC travel warnings, medicines, offices, phone numbers, opening hours, salaries and shopping.
- **[Pseudo Personalised Spam Classifier](https://github.com/danielrosehill/Pseudo-Personalised-Spam-Classifier)** (GitHub, Documentation): Small classifier separating genuine stranger email from AI-era pseudo-personalised mass outreach that evades spam filters. Public, pseudonymised dataset.
- **[RTL Skills](https://github.com/danielrosehill/RTL-Skills)** (GitHub, Agent plugin): Right-to-left skills for AI agents: Hebrew and RTL email, Typst PDFs, letters, HTML newsletters, Google Workspace and generated files
- **[Voice Note Task Classifier](https://github.com/danielrosehill/Voice-Note-Task-Classifier)** (GitHub, Documentation): Small multi-label classifier that routes voice-note transcripts to task-specific subagents (email, calendar, to-do, spec...). Public successor of v0.1.0.
