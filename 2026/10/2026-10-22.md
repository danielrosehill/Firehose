# 22 October 2026

Agent plugins for Claude Code covered microphone tuning, music video generation, planning documents, spending limits, Ubuntu hotkeys and vendor bug reporting. Election work included a 2026 Knesset model and reference datasets on the outgoing Knesset, candidate lists and polls. A voice-clone conversation and its alignment data rounded out the repositories.

## GitHub Repositories

8 repos created

- **[ASR Mic Tuner](https://github.com/danielrosehill/ASR-Mic-Tuner)** (GitHub, Tool): ASR Mic Tuner: tune your microphone for speech recognition on KDE Plasma — true analog gain, level, clipping, noise and voice analysis, tray
- **[Claude AVP Music Video Plugin](https://github.com/danielrosehill/Claude-AVP-Music-Video-Plugin)** (GitHub, Agent plugin): Claude Code plugin: turn audio (e.g. Suno songs) into branded music videos with audio-visualizer-python (avp) — templates, brand kit, karaoke lyrics, AV1 encode
- **[Claude Planning Docs Plugin](https://github.com/danielrosehill/Claude-Planning-Docs-Plugin)** (GitHub, Agent plugin): Claude Code plugin: keep a repo's decision log and plans lean — record numbered decisions, compact old decisions and plans in place.
- **[Claude Spend Approval Limit](https://github.com/danielrosehill/Claude-Spend-Approval-Limit)** (GitHub, Documentation): CLAUDE.md snippet: a spending approval limit for AI agents — autonomous below it, estimate-and-ask above it
- **[Claude Ubuntu Hotkey Builder](https://github.com/danielrosehill/Claude-Ubuntu-Hotkey-Builder)** (GitHub, Agent plugin): Claude plugin: find free keys and build working shortcuts, macros and text-injection hotkeys on Ubuntu (X11/Wayland, KDE/GNOME)
- **[Israeli Elections 2026](https://github.com/danielrosehill/Israeli-Elections-2026)** (GitHub, Tool): Modelling the 2026 Israeli Knesset election
- **[Me And My Voice Clone](https://github.com/danielrosehill/Me-And-My-Voice-Clone)** (GitHub, Documentation): A ten-minute conversation between me and a TTS clone of my own voice (Meorav v2.0, Qwen3-TTS fine-tune): original video, audio, per-line clips, alignment data and splice pipeline
- **[Vendor Liaison](https://github.com/danielrosehill/Vendor-Liaison)** (GitHub, Agent plugin): Report bugs, request features and disclose security issues to software vendors: structured channel data per vendor, routing rules, and your own preferred channels and contacts. Agent skills.

## Datasets

3 datasets created

- **[Israel Election 2026 Candidate Lists](https://huggingface.co/datasets/danielrosehill/Israel-Election-2026-Candidate-Lists)** (Hugging Face, Reference dataset): This dataset contains every candidate list for the election to the 26th Knesset, held on 27 October 2026.
- **[Israel Election 2026 Polls](https://huggingface.co/datasets/danielrosehill/Israel-Election-2026-Polls)** (Hugging Face, Reference dataset): This dataset contains every published seat-projection poll for the 27 October 2026 Knesset election, from 23 December 2022 to 22 October 2026.
- **[Israel Knesset 25 Members](https://huggingface.co/datasets/danielrosehill/Israel-Knesset-25-Members)** (Hugging Face, Reference dataset): This dataset covers the outgoing 25th Knesset, elected on 1 November 2022, at the end of its term ahead of the 27 October 2026 election.
