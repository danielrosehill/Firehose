# Firehose wrap-up for September 2026

9 repos, 1 dataset, 1 model created across 4 days.

## GitHub Repositories

9 repos created

- 2026-09-01: **[Claude Eml Toolkit](https://github.com/danielrosehill/Claude-Eml-Toolkit)** (GitHub, Tool): Claude Code plugin for turning .eml email exports into artefacts you can actually use — a threaded PDF of a correspondence chain, extracted attachments, Markdown for another agent, a redacted copy...
- 2026-09-01: **[Claude Timemark Plugin](https://github.com/danielrosehill/Claude-Timemark-Plugin)** (GitHub, Agent plugin): Handle Timemark (Android stamp camera) exports: which route preserves pixels vs field values, and the join that recovers both
- 2026-09-01: **[Jerusalem Graffiti](https://github.com/danielrosehill/Jerusalem-Graffiti)** (GitHub, Tool): Field photography of a messianic postering campaign in central Jerusalem, with the coordinates of every shot.
- 2026-09-01: **[Jerusalem Projects Index](https://github.com/danielrosehill/Jerusalem-Projects-Index)** (GitHub, Documentation): Projects tied to Jerusalem as a place — the city, its streets, its municipal services and specific addresses within it.
- 2026-09-04: **[HA Circadian Red Shift](https://github.com/danielrosehill/HA-Circadian-Red-Shift)** (GitHub, Documentation): Home Assistant blueprint: three-phase circadian lighting — full white by day, warmest Kelvin after sunset, then true RGB red until dawn. For lights that support both colour temperature and colour.
- 2026-09-17: **[Claude IKEA Israel Plugin](https://github.com/danielrosehill/Claude-IKEA-Israel-Plugin)** (GitHub, Agent plugin): Claude Code plugin: per-branch stock counts, aisle/bin locations and ILS prices for IKEA Israel's five stores, from the Hebrew/RTL site.
- 2026-09-17: **[Dremel 7760 USB C Retrofit](https://github.com/danielrosehill/Dremel-7760-USB-C-Retrofit)** (GitHub, Documentation): Teardown photos, a diagnosis, and parts lists for a Dremel 7760 Lite whose charging port gave up three months after I bought it.
- 2026-09-22: **[Android Voice Keyboard Roundup](https://github.com/danielrosehill/Android-Voice-Keyboard-Roundup)** (GitHub, Tool): Evaluation matrix for open-source Android voice keyboards: voice IME vs full keyboard vs floating button, local vs cloud vs automatic fallback, and which ASR model
- 2026-09-22: **[Hebrew Small Models Planning](https://github.com/danielrosehill/Hebrew-Small-Models-Planning)** (GitHub, Tool): Planning repository for a small-model layer that fixes Hebrew pronunciation in the My Weird Prompts podcast's text-to-speech output.
