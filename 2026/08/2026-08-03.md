# 3 August 2026

Agent tooling covered standing instructions for AI agents and a Claude Code plugin for Israeli phonebook entries in Google Contacts. A training dataset classified household and small business goods hierarchically, with handling attributes on each class.

## GitHub Repositories

2 repos created

- **[Agent Habits](https://github.com/danielrosehill/Agent-Habits)** (GitHub, Tool): Standing instructions for AI agents: habits (rules) and SOPs (procedures), one markdown file each, with a library of example habits to adopt and a small generated system-prompt block.
- **[Israel Phonebook Manager](https://github.com/danielrosehill/Israel-Phonebook-Manager)** (GitHub, Agent plugin): Claude Code plugin for creating and maintaining Israeli phonebook entries in Google Contacts — counter vs call-centre hours, Shabbat and chag closures, seasonal timetables, star and 1-800 numbers...

1 dataset created

- **[Homegoods Taxonomy](https://huggingface.co/datasets/danielrosehill/homegoods-taxonomy)** (Hugging Face, Training dataset): A hierarchical classification of the physical goods in an ordinary home or small business, with a physical handling attribute layer attached to every class.
