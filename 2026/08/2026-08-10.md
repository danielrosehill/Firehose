## GitHub Repositories

9 repos created

- **[Agent Reference Workflows](https://github.com/danielrosehill/Agent-Reference-Workflows)** (GitHub, Agent plugin): Index of repositories that each demonstrate one agentic workflow end to end — kept as working context for designing plugins: what the workflow is, where it worked, and where it broke.
- **[Agentic Purchase Pipeline](https://github.com/danielrosehill/Agentic-Purchase-Pipeline)** (GitHub, Documentation): A staged, agent-supported process for evaluating any purchase over ~$50: capture the spec, find the requirement no vendor publishes, revise the spec as research lands, and decide on landed cost.
- **[AI Assisted Policymaking Index](https://github.com/danielrosehill/AI-Assisted-Policymaking-Index)** (GitHub, Documentation): Index of repositories that use AI to formulate and explore public policy — manifestos, policy papers, multi-lens deliberation runs, and the research workspaces behind them.
- **[Claude Fleet Traffic Shaper](https://github.com/danielrosehill/Claude-Fleet-Traffic-Shaper)** (GitHub, Documentation): Priority-aware traffic shaping for a fleet of concurrent Claude Code sessions — spec and prior-art research
- **[Claude For Mayor](https://github.com/danielrosehill/Claude-For-Mayor)** (GitHub, Tool): An AI-assisted municipal platform for a candidate who doesn't exist — a Jerusalem mayoral manifesto built properly: testimony, evidence, comparator cities, costed proposals, and a rule that nothing...
- **[Claude Shopping Eval Demo](https://github.com/danielrosehill/Claude-Shopping-Eval-Demo)** (GitHub, Evaluation): A demo of using Claude Code as a consumer purchasing assistant — spec + retailer catalogue screenshots in, ranked recommendations as a typeset PDF out.
- **[Israel ADHD Medication Access](https://github.com/danielrosehill/Israel-ADHD-Medication-Access)** (GitHub, Documentation): A documented, redacted case record of trying to obtain prescribed ADHD medication in Israel — the published rules, the referral loop, and the regulation nobody mentioned
- **[Virtual Macropad](https://github.com/danielrosehill/Virtual-Macropad)** (GitHub, Tool): A software macropad for laptop users: press a leader key, a grid appears, press one more key, the macro fires.
- **[Zalias](https://github.com/danielrosehill/zalias)** (GitHub, Tool): Bridge shell aliases and zoxide: name a directory whatever you actually call it, and let z find it. Aliases become real zoxide entries, so fuzzy matching and frecency apply to them too.
