# 12 August 2026

Nine repositories cover Claude Code tooling and workflow. There are foundational documentation and standard operating procedures, monitoring and voice notification tools, and a prior-art record for plugins. Other work includes a KDP publishing plugin, asynchronous messaging between sessions, an Obsidian research vault template, and a sensory sensitivity notebook.

## GitHub Repositories

9 repos created

- **[Claude Foundations](https://github.com/danielrosehill/Claude-Foundations)** (GitHub, Documentation): The foundational layer of a Claude Code setup, indexed as one system: five slots — entrypoint, reference context, standing directives, procedures, capability — the repos that own each, and the order...
- **[Claude Monitor Research](https://github.com/danielrosehill/Claude-Monitor-Research)** (GitHub, Tool): What a multi-pane Claude Code workflow actually needs from a display, measured in text cells rather than inches
- **[Claude SOPs](https://github.com/danielrosehill/Claude-SOPs)** (GitHub, Tool): Keep your own standard operating procedures as a private, versioned markdown library that Claude Code reads on demand — one CLAUDE.md pointer, one index, one procedure per run.
- **[Claude Tooling Prior Art](https://github.com/danielrosehill/Claude-Tooling-Prior-Art)** (GitHub, Agent plugin): Public record of prior-art scans for Claude Code tooling — does a plugin/MCP/skill already exist for this, or is it blue sky? Dated verdicts, with the searches that produced them.
- **[Claude Voice Notifier](https://github.com/danielrosehill/Claude-Voice-Notifier)** (GitHub, Documentation): Planning repo: Claude places an outbound phone call to deliver a one-time, task-specific spoken notification on your behalf. Twilio + per-call agent instructions.
- **[KDP Publishing Plugin](https://github.com/danielrosehill/KDP-Publishing-Plugin)** (GitHub, Agent plugin): Claude Code plugin: typeset a print-ready Amazon KDP paperback with Typst.
- **[Multisession](https://github.com/danielrosehill/Multisession)** (GitHub, Tool): Asynchronous agent-to-agent messages between Claude Code sessions in different repos: a markdown mailbox in each repo's a2a/ folder, a SessionStart hook, reminders and living messages. No server.
- **[Obsidian Research Vault Template](https://github.com/danielrosehill/Obsidian-Research-Vault-Template)** (GitHub, Agent plugin): GitHub template for AI-assisted research that produces a working Obsidian vault, not a folder of markdown.
- **[Sensory Notebook](https://github.com/danielrosehill/Sensory-Notebook)** (GitHub, Tool): An open notebook on sensory sensitivity — research Q&A with sourced answers, alongside my own sensory profile, story and the recommendations that actually worked. Not medical advice.
