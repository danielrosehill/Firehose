# 17 August 2026

Three repositories cover durable goods and industrial purchasing: a directory of long lasting product recommendations with supporting evidence, a Claude Code plugin for researching industrial supplies on Grainger, and a notebook mapping consumer categories to industrial equivalents and whether the swap is worthwhile.

## GitHub Repositories

3 repos created

- **[BIFL Recs](https://github.com/danielrosehill/BIFL-Recs)** (GitHub, Tool): Directory of durable-goods recommendations mined from r/BuyItForLife and adjacent sources, with evidence attached to every record
- **[Claude Grainger Plugin](https://github.com/danielrosehill/Claude-Grainger-Plugin)** (GitHub, Agent plugin): Claude Code plugin for product research on Grainger.com (US industrial MRO) — mapped API surface, facet grammar, branch stock, and HTTP-200 block classification
- **[Industrial Equivalents](https://github.com/danielrosehill/Industrial-Equivalents)** (GitHub, Tool): A public notebook mapping consumer product categories onto their industrial equivalents — and whether the swap is worth making at home
