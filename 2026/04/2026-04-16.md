# 16 April 2026

Agent plugins for Claude Code covered purchase research, persistent user memory, GitHub discovery, skill authoring, and Typst document templates. Two repositories held bug reports and feature requests for Claude Code and research notes on skill creation. A separate tool remapped a generic USB button to F13 on Linux and Wayland.

## GitHub Repositories

7 repos created

- **[Agent Assisted Purchase Research Index](https://github.com/danielrosehill/Agent-Assisted-Purchase-Research-Index)** (GitHub, Agent plugin): Index of templates, agent skills, and demos for the pattern of using AI agents to drive consumer purchase research — spec-first, then product matching, then availability checks
- **[Claude Code Bugs And FRs](https://github.com/danielrosehill/Claude-Code-Bugs-And-FRs)** (GitHub, Documentation): Staging area for Claude Code bug reports and feature requests before filing upstream at anthropics/claude-code
- **[Claude User Memory Plugin](https://github.com/danielrosehill/Claude-User-Memory-Plugin)** (GitHub, Agent plugin): Claude Code plugin: user memory and personalization workflow — recall, save, and inject persistent facts across sessions.
- **[GitHub Research Plugin](https://github.com/danielrosehill/github-research-plugin)** (GitHub, Agent plugin): Explore existing GitHub repositories before building something yourself. This plugin is focused exclusively on research and discovery — it does not perform any GitHub write operations.
- **[Skill Creation Research](https://github.com/danielrosehill/Skill-Creation-Research)** (GitHub, Agent plugin): Open research workspace for Claude Code skill creation — patterns, best practices, skill authoring experiments
- **[Typst Document Generator Plugin](https://github.com/danielrosehill/typst-document-generator-plugin)** (GitHub, Agent plugin): Typst document templates as agent skills: generic built-in formats (docs, briefings, screenplay) plus a private overlay for your own
- **[USB Button Remap](https://github.com/danielrosehill/USB-Button-Remap)** (GitHub, Tool): Remap a generic USB HID button (vendor 5131:2019) to F13 on Linux/Wayland using keyd
