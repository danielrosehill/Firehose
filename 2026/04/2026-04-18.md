# 18 April 2026

Agent plugins for development bug tracking and MQTT broker observation sit alongside a tool that tests hypotheses across three models. A planning workspace for home media setup rounds out the repositories.

## GitHub Repositories

4 repos created

- **[Dev Debugger Plugin](https://github.com/danielrosehill/dev-debugger-plugin)** (GitHub, Agent plugin): Bug-ticket workflow for development repos. Capture bugs into the repo itself, dispatch specialist remediation agents, document fixes privately, and ship releases — all through Claude Code.
- **[Home Media Planner](https://github.com/danielrosehill/Home-Media-Planner)** (GitHub, Documentation): Planning workspace for home media setup — idea parking and specs
- **[Hypothesis Council](https://github.com/danielrosehill/Hypothesis-Council)** (GitHub, Tool): Hypothesis-testing variant of the LLM council pattern — 3 diverse models (Sonnet, Grok, MiniMax) via OpenRouter, Sonar grounding, Typst report
- **[Mqtt Observability Plugin](https://github.com/danielrosehill/mqtt-observability-plugin)** (GitHub, Agent plugin): Observe and interact with an MQTT broker from inside Claude Code — monitor all traffic, watch a specific topic, or publish a payload. Credentials are collected once and reused across invocations.
