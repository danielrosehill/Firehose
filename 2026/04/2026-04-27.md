# 27 April 2026

Agent plugins for Claude Code covered data annotation, digital printing, KDE plasmoid development, programmatic document generation, Linux packaging, and social discourse research. Other repositories included Hebrew fonts, a KDE Plasma time widget, and notes on prompt categorisation. A training dataset decomposed voice-typed podcast prompts into asks, context chunks, and host notes.

## GitHub Repositories

10 repos created

- **[Awesome Hebrew Fonts](https://github.com/danielrosehill/Awesome-Hebrew-Fonts)** (GitHub, Tool): Collection of Hebrew fonts, installer for Google Font distributed versions, and some resources
- **[Claude Data Annotation Plugin](https://github.com/danielrosehill/Claude-Data-Annotation-Plugin)** (GitHub, Agent plugin): End-to-end toolkit for turning raw data into an annotated dataset and publishing it to Hugging Face.
- **[Claude Digital Printing Plugin](https://github.com/danielrosehill/Claude-Digital-Printing-Plugin)** (GitHub, Agent plugin): A Claude Code plugin with skills for preparing PDFs and documents for digital printing.
- **[Claude KDE Plasmoid Dev Plugin](https://github.com/danielrosehill/Claude-KDE-Plasmoid-Dev-Plugin)** (GitHub, Agent plugin): A Claude Code plugin that adds a skill for developing KDE Plasma plasmoids — desktop and panel widgets built in QML and packaged for the Plasma shell.
- **[Claude MD Experiments](https://github.com/danielrosehill/Claude-MD-Experiments)** (GitHub, Documentation): No description published.
- **[Claude Programmatic Doc Generation Plugin](https://github.com/danielrosehill/Claude-Programmatic-Doc-Generation-Plugin)** (GitHub, Agent plugin): A Claude Code plugin for building programmatic document generation pipelines.

- **[Linux Packaging Plugin](https://github.com/danielrosehill/Linux-Packaging-Plugin)** (GitHub, Agent plugin): Skills for Linux packaging and release workflows — Debian/.deb builds, npm publishing, GitHub release creation, agent deploy scripts, and local debugging.
