# 2 November 2026

New repositories covered agent tooling and local speech work, with two agent plugins for text-to-speech and staged transcription. Other projects included a handwriting recognition model, an Android clock widget, a manual-rewriting tool, and Konsole settings for Claude Code sessions. On Hugging Face, the new dataset was one speaker reading desktop voice commands.

## GitHub Repositories

7 repos created

- **[Claude Konsole Setup](https://github.com/danielrosehill/Claude-Konsole-Setup)** (GitHub, Tool): Konsole settings for running Claude Code sessions: window-close protection, no single-tab prompt, split layout; apply.sh for other machines
- **[Daniel Handwriting Recognition](https://github.com/danielrosehill/Daniel-Handwriting-Recognition)** (GitHub, Tool): Fine-tuning a handwriting recognition (HTR) model on Daniel's handwriting: data collection plan, ground truth, training
- **[Laptop Search 1126](https://github.com/danielrosehill/Laptop-Search-1126)** (GitHub, Documentation): Laptop search, November 2026: requirements, spec notes and voice-note transcripts.
- **[Local TTS Plugin](https://github.com/danielrosehill/Local-TTS-Plugin)** (GitHub, Agent plugin): Local text-to-speech for Claude Code: Kokoro (CPU), NeuTTS Air (CPU cloning), Chatterbox (ROCm/CUDA). Installs, registers and runs local TTS models.
- **[Local UTC Widget](https://github.com/danielrosehill/Local-UTC-Widget)** (GitHub, Tool): Android home-screen widget: local time and UTC side by side, 24-hour, with optional date, UTC offset and font choice
- **[Transcription Pipeline](https://github.com/danielrosehill/Transcription-Pipeline)** (GitHub, Agent plugin): Agent skills for transcription in stages: retrieve, preprocess (EQ, denoise, VAD), transcribe (OpenRouter/Gemini, AssemblyAI, local Whisper/Parakeet), clean, label speakers, reshape, Typst PDF, save
- **[Useful User Manuals](https://github.com/danielrosehill/Useful-User-Manuals)** (GitHub, Tool): Turn bloated product manuals into useful ones: fetch, trim to your language, rewrite, or one-task how-to PDFs, always citing the original.
