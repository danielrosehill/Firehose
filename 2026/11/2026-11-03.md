# 3 November 2026

New repositories covered agent tooling and home network security, with three agent plugins and a playbook for keeping cheap IP cameras local-only. On Hugging Face, the new work was speech-recognition training material: a small model that writes read-aloud sentences, its training data, and a mixed English-Hebrew sentence dataset.

## GitHub Repositories

4 repos created

- **[ChatGPT Workspace Agents Claude Plugin](https://github.com/danielrosehill/ChatGPT-Workspace-Agents-Claude-Plugin)** (GitHub, Agent plugin): Builds and manages ChatGPT Workspace Agents from Claude Code by driving the agent builder in a browser, since OpenAI has no public API for creating them.
- **[Guava Health Plugin](https://github.com/danielrosehill/Guava-Health-Plugin)** (GitHub, Agent plugin): Unofficial plugin and Python CLI for the Guava Health API: logs medications, symptoms and readings, and reviews the data, including for dependents on a family plan.
- **[IP Cam Lockdown](https://github.com/danielrosehill/IP-Cam-Lockdown)** (GitHub, Documentation): Forensics and a playbook for running cheap AliExpress IP cameras local-only: how each one reaches the vendor cloud, and how to cut it off.
- **[Network Forensics Plugin](https://github.com/danielrosehill/Network-Forensics-Plugin)** (GitHub, Agent plugin): Skills for tracing what a device on a home network talks to, documenting it, blocking it at the firewall and verifying the lockdown.

## Datasets

2 datasets created

- **[English Hebrew Mixed Sentences](https://huggingface.co/datasets/danielrosehill/English-Hebrew-Mixed-Sentences)** (Hugging Face, Training dataset): English sentences with Hebrew words and phrases mixed in, for training and evaluating speech-to-text for English speakers in Israel.
- **[Term Context Sentences](https://huggingface.co/datasets/danielrosehill/term-context-sentences)** (Hugging Face, Training dataset): Training data for writing short read-aloud sentences that use a given term in a given context, covering romanized Hebrew and Yiddish, Israeli names and tech vocabulary.

## AI Models

2 models created

- **[Contextual Sentence Creator](https://huggingface.co/danielrosehill/Contextual-Sentence-Creator)** (Hugging Face, Fine-tuned model): LoRA fine-tune of Granite 4.2 3B that returns natural sentences using a given term in a given context, for recording speech-recognition training data.
- **[Contextual Sentence Creator GGUF](https://huggingface.co/danielrosehill/Contextual-Sentence-Creator-GGUF)** (Hugging Face, Quantised model): GGUF builds of Contextual-Sentence-Creator in Q4_K_M and Q8_0, for running it with llama.cpp.
