# 6 May 2026

Agent plugins for Claude covered decision logging, document nudging, and Linux audio preset management, alongside work-in-progress skill baskets for Israeli mortgage and property research. Documentation and datasets centred on Israeli open data, with bilingual catalogue translations and a reference snapshot of data.gov.il.

## GitHub Repositories

10 repos created

- **[Claude Decision Mapper](https://github.com/danielrosehill/Claude-Decision-Mapper)** (GitHub, Documentation): A repository for mapping and codifying an iterative spec-refinement process used with Claude (and applicable to other LLM-driven planning conversations).
- **[Claude Document Nudge](https://github.com/danielrosehill/Claude-Document-Nudge)** (GitHub, Tool): A snippet (and thin plugin wrapper) that nudges Claude to document decisions, todos, sprints, and handovers as we work — without being asked each time.
- **[Claude Shopping Demo 2](https://github.com/danielrosehill/Claude-Shopping-Demo--2)** (GitHub, Documentation): model for a claude shopping research tool customised by shops + tasks
- **[Easy Effects Manager](https://github.com/danielrosehill/Easy-Effects-Manager)** (GitHub, Agent plugin): Claude-Controller plugin for managing Easy Effects on Linux: preset library, autoload bindings, level testing, voice-dictation setup
- **[Easy Effects Presets](https://github.com/danielrosehill/Easy-Effects-Presets)** (GitHub, Documentation): My Easy Effects input presets
- **[Israel Agent Skills Dev Index](https://github.com/danielrosehill/Israel-Agent-Skills-Dev-Index)** (GitHub, Agent plugin): Index of WIP skills-development repos feeding into Israel-Agent-Skills-Dev / Claude-Israel-Agent-Skills-Plugin.
- **[Israel Mortgage Research Skills](https://github.com/danielrosehill/Israel-Mortgage-Research-Skills)** (GitHub, Agent plugin): WIP skills basket for Israeli residential mortgage research (track mix, BoI rules, DSR/LTV, bank quirks). Verified skills graduate to Israel-Agent-Skills-Dev.
- **[Israel Open Data Catalogue Translations](https://github.com/danielrosehill/Israel-Open-Data-Catalogue-Translations)** (GitHub, Documentation): Hebrew/English translation mapping for every dataset on data.gov.il
- **[Israel Open Data Resources](https://github.com/danielrosehill/Israel-Open-Data-Resources)** (GitHub, Tool): Open access data and a list of Israeli data projects
- **[Israel Property Research Skills](https://github.com/danielrosehill/Israel-Property-Research-Skills)** (GitHub, Agent plugin): WIP skills basket for Israeli property due diligence (Tabu, tik binyan, shimush choreg, comps). Verified skills graduate to Israel-Agent-Skills-Dev.
