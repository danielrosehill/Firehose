## How it works

Entries live at `YYYY/MM/YYYY-MM-DD.json`, with a generated `.md` beside each. One entry per day on which a public project was created, midnight to midnight Israel time (`Asia/Jerusalem`). Scripts assemble everything except a short intro paragraph, which a model writes. Pipeline and schema: [FORMAT.md](FORMAT.md).

Read it on [the blog](https://blog.danielrosehill.com/firehose/), by [RSS](https://blog.danielrosehill.com/firehose/rss.xml) or as [JSON](https://blog.danielrosehill.com/firehose/feed.json).

Forks, private repositories, gated Hugging Face items and this repository are left out. The 2026-11-04 entry predates this format.
