# Firehose wrap-up for December 2024

21 repos, 2 datasets created across 13 days.

## GitHub Repositories

21 repos created

- 2024-12-02: **[Eco Ninja 3](https://github.com/danielrosehill/Eco-Ninja-3)** (GitHub, Documentation): Configuration for an LLM assistant that performs analysis on sustainability data
- 2024-12-04: **[GHG EBITDA Correlations](https://github.com/danielrosehill/GHG-EBITDA-Correlations)** (GitHub, Tool): Streamlit data visualisation examining correlation between emissions & profitability
- 2024-12-04: **[Monetised GHG Emissions](https://github.com/danielrosehill/Monetised-GHG-Emissions)** (GitHub, Tool): Calculating monetised GHG emissions for various companies based upon disclosure data
- 2024-12-05: **[Value Factors Data Vis](https://github.com/danielrosehill/Value-Factors-Data-Vis)** (GitHub, Tool): Streamlit app containing visualisations of the Global Value Factors Database (GVFD) released by the IFVI in 2024
- 2024-12-08: **[Data Projects Index](https://github.com/danielrosehill/Data-Projects-Index)** (GitHub, Documentation): Data apps and datasets deployed to Streamlit Community Cloud, Hugging Face, and elsewhere.
- 2024-12-08: **[Sustainability Report Data Extractor](https://github.com/danielrosehill/Sustainability-Report-Data-Extractor)** (GitHub, Tool): Tool for extracting data-containing pages from sustainability reports
- 2024-12-09: **[GHG Emissions Data Pipeline](https://github.com/danielrosehill/GHG-Emissions-Data-Pipeline)** (GitHub, Tool): Data pipeline repository supplying various data visualisation projects
- 2024-12-09: **[GHG Vs EBITDA V2](https://github.com/danielrosehill/GHG-vs-EBITDA-V2)** (GitHub, Documentation): Another data visualisation series comparing companies' GHG emissions with their EBITDA
- 2024-12-09: **[My Calculators](https://github.com/danielrosehill/My-Calculators)** (GitHub, Documentation): Unit exchange calculators for calculations I commonly require
- 2024-12-10: **[LLM Long Codegen Test](https://github.com/danielrosehill/LLM-Long-Codegen-Test)** (GitHub, Tool): Experiment to evaluate the ability of code-gen LLMs to generate a long continuous (single) output
- 2024-12-17: **[Bias Censorship Eval Tests](https://github.com/danielrosehill/Bias-Censorship-Eval-Tests)** (GitHub, Evaluation): Some loosely organised experiments intended to probe the levels of political censorship inherent in LLMs
- 2024-12-17: **[Claude Anonymisation Assistant Plugin](https://github.com/danielrosehill/Claude-Anonymisation-Assistant-Plugin)** (GitHub, Agent plugin): Configuration for a large language assistant designed to assist with redacting personally identifiable details in documents
- 2024-12-18: **[Context Waterfall Architecture Notes](https://github.com/danielrosehill/Context-Waterfall-Architecture-Notes)** (GitHub, Documentation): A model for routing contextual data into vector storage for use with LLMs
- 2024-12-19: **[Emissions Monetisation Calculator](https://github.com/danielrosehill/Emissions-Monetisation-Calculator)** (GitHub, Tool): Calculation tool for "monetising" companies' emissions at various proposed social cost of carbon values
- 2024-12-20: **[Global Value Factors Explorer Dataset](https://github.com/danielrosehill/Global-Value-Factors-Explorer-Dataset)** (GitHub, Documentation): Derivative database of IFVI Global Value Factors for data analysis and visualization use cases.
- 2024-12-20: **[Mock PII Data](https://github.com/danielrosehill/Mock-PII-Data)** (GitHub, Tool): Synthetic data containing personally identifiable information
- 2024-12-24: **[Context Data Generation Bot](https://github.com/danielrosehill/Context-Data-Generation-Bot)** (GitHub, Documentation): Configuration for an AI assistant to generate personal contextual data (and intended workflow)
- 2024-12-24: **[Corn The Sloth Public](https://github.com/danielrosehill/Corn-The-Sloth-Public)** (GitHub, Documentation): Character sketches for an AI character...
- 2024-12-24: **[GVFD Explorer Chatbot V2](https://github.com/danielrosehill/GVFD-Explorer-Chatbot-V2)** (GitHub, Documentation): Chatbot supporting user discovery of the global value factors database
- 2024-12-29: **[Perplexity Security 1224](https://github.com/danielrosehill/Perplexity-Security-1224)** (GitHub, Documentation): Repository to demonstrate the "security through security" being currently implemented
- 2024-12-30: **[Gmail Search Strings](https://github.com/danielrosehill/Gmail-Search-Strings)** (GitHub, Documentation): Just a few search strings for finding stuff in overcrowded Gmail inboxes!
