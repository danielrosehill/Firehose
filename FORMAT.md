# Firehose entry format

Status: draft since 2026-11-04, sample entry `2026/11/2026-11-03.json`, awaiting Daniel's review on the blog.

An entry lists the public projects created on one day (midnight to midnight, `Asia/Jerusalem`). Backfilled entries hold created projects only, because GitHub keeps a reliable `created_at` but not a day-by-day activity history. A day with no created projects gets no entry.

## Files

- `YYYY/MM/YYYY-MM-DD.json`: the source. This is the only file an agent writes.
- `YYYY/MM/YYYY-MM-DD.md`: generated by `scripts/render_entry.py <json>`. Never edit it by hand.
- `entries.json` (repo root): every JSON entry, newest first, generated by `scripts/update_index.py`. The blog reads this at build time.

## JSON schema

```json
{
  "date": "2026-11-03",
  "summary": "One sentence naming what was created.",
  "scope": "created",
  "projects": [
    {
      "name": "Network-Forensics-Plugin",
      "url": "https://github.com/danielrosehill/Network-Forensics-Plugin",
      "network": "GitHub",
      "section": "repos",
      "type": "Agent plugin",
      "description": "One plain sentence saying what it is."
    }
  ]
}
```

| Field | Allowed values |
| --- | --- |
| `network` | `GitHub`, `Hugging Face` |
| `section` | `repos` (GitHub Repositories), `datasets` (Datasets), `models` (AI Models) |
| `type` for `repos` | `Agent plugin`, `MCP server`, `Application`, `Tool`, `Website`, `Documentation`, `Prompt collection`, `Evaluation`, `Other` |
| `type` for `datasets` | `Training dataset`, `Evaluation dataset`, `Audio dataset`, `Reference dataset`, `Other` |
| `type` for `models` | `Fine-tuned model`, `Quantised model`, `Other` |

`render_entry.py` rejects anything outside these values. Sections render in the order above, and a section with no projects has no header.

## Writing rules

- `description`: one sentence, about 25 words at most, taken from the repo description, README or model card. Say what the thing is, never guess. No hype, no emojis.
- `summary`: one sentence, used as the list line on the blog and in the indexes.
- Forks, private repositories, gated Hugging Face items and this repository are left out.
